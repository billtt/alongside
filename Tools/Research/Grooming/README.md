# 从家猫理毛记录学习部位选择

达达的 58 参数网络读取最近两个短组洗过的部位，预测这一轮可能继续把时间花在哪里。每个短组由 2–4 次舔舐组成，洗脸还包括用湿爪擦脸。再次选择同一处时维持当前姿势；换部位时经过收脚或放爪的绘稿。自然理毛可在一组完成后收势，最多八组。菜单“洗洗脸”展示四种已有绘稿的部位，从洗脸开始，余下部位通过同一个网络采样。

## 来源与含义

模型在本机从 Manuela Schmidt 发布的家猫理毛百分比表拟合。原表按场次列各部位时间占比，含 40 场、10 个不同猫 ID，39 场包含可映射的部位。数据网页摘要写有 8 只猫，工作簿中可直接数出 10 个 ID，与论文样本 B 相符。四组映射为脸部六个目标与前爪、胸口、肩与侧腹、后爪。四组以外的观察时间被排除，每个纳入场次在这些目标上的总占比平均为 44.62%。部位映射与网络参数由 Alongside 衍生，数据采用 CC BY 4.0。[Manuela Schmidt，数据与许可](https://data.mendeley.com/datasets/x5c38ztg9m/1) · [Hock 与 Schmidt，采集方法与样本组成](https://pmc.ncbi.nlm.nih.gov/articles/PMC13631463/)

把每场的四项时间占比归一化，就得到在这场理毛中任选一个时刻落在各部位的概率。网络学习的是已知同一场中的一至两个抽样部位，再选一个时刻会落在哪里。训练对所有部位组合计算精确的概率质量，给各只猫相同权重，同猫各场等权。原表缺少逐次舔舐的先后时间戳，所以这里测到的是部位共现。应用用它生成连贯的部位偏向。擦脸的动作顺序、每组舔几下、姿势间如何走以及菜单约束，均由桌面动作设计提供。

另一批 Smit 的真实观察记录包含逐秒的总体理毛标注。自然理毛每完成一组，按自上次检查以来实耗的整数秒累乘原有理毛持续概率，再决定是否收势。持续时长与部位选择来自独立样本。两者均从真实观察估计，主人已有的互动偏好继续单独保存在本机。[Smit 数据与时长估计](../ObservedBehavior/README.md)

## 复训与留出验证

需 Python 3、NumPy 和 SciPy。在项目根目录运行以下命令。训练工具核对原表 SHA-256，标准库读取工作表。训练过程中不上传文件。

```sh
mkdir -p local-work/grooming-policy
curl -fL 'https://data.mendeley.com/public-files/datasets/x5c38ztg9m/files/e50c85bc-078e-4b43-88d7-b45ff0d054f9/file_downloaded' -o local-work/grooming-policy/observations.xlsx
python3 -B Tools/Research/Grooming/train.py local-work/grooming-policy/observations.xlsx Resources/Pets/Dada/Behavior/grooming-v1.json
```

每轮留出一整只猫，同一只猫的片段不会出现在训练和验证两侧。每只猫分别计算在已知一个或两个同场部位时预测另一时间样本的交叉熵，再对猫等权平均。结果越低越好。

| 方法 | 条件交叉熵 |
| --- | ---: |
| 固定部位比例 | 1.0984 |
| 同场部位共现计数，加平滑 | 1.0103 |
| 本地小网络 | 1.0096 |

两种利用同场部位的模型表现接近。在全量拟合的网络上，没有本轮历史时后爪获得 12.3% 的概率，已在后爪做过两组时为 47.8%。这些是达达可执行部位之间的相对概率。头肩的可见运动幅度由原画决定，模型验证也不衡量该视觉效果。应用的动作检查另用固定种子回放 64 场，检查收势、持续同处以及短洗和长洗是否均会出现。

### 加入新的观察

可按录像逐场记录达达能画出的四种部位各花多少秒，再在命令末尾添加 `--additional 新观察.csv`。每行是一只猫的一场理毛，表头如下。填入实际记录到的秒数，未观察到的部位填 0。各场至少有一个可用部位。使用稳定、匿名的组别、猫和场次编号，同一只猫的多场观察才会在留出时分到同一侧。原表与新增场次一起训练，主人互动档案单独保存。训练时可先把输出指向临时文件，查看新权重在整猫留出中的变化。

```text
cohort,cat_id,bout_id,paw_face_seconds,chest_seconds,shoulder_flank_seconds,hind_paw_seconds
```
