# 达达的本地行为学习实验

实验用人工生成的动作标签和两位虚构主人的反馈，检验基础行为和个人偏好能否分别更新。所有输入都是相互独立的决策场景，未采集真猫或真实用户的数据。

在项目根目录运行，需要 Python 3 和 NumPy。默认在临时目录写入并重新载入权重，退出后自动清理。若要保留两份基础模型和两份个人档案，可以用 `--output-dir` 指定一个新的输出目录。

```sh
python3 -B Tools/Research/CatPolicy/experiment.py
```

**基础行为**。用六个归一化量描述距今最近的触摸是否发生在头部或敏感部位、近期打扰程度、休息倾向、维持姿势的时间和指针接近程度。实验直接抽取这些量，实际应用需要从事件历史估计。6→16→4 的神经网络共 180 个参数，在每次决策时预测继续休息、回看、理毛、走开四种意图的概率。8,192 个训练场景各从预设概率分布抽取一个动作标签。4,096 个留出场景使用独立随机数生成且不参与训练。按训练集的固定动作频率预测，留出负对数似然为 1.304，网络为 0.945，数值越低表示给留出动作分配的概率平均越高。

**个人偏好**。在温和头部触摸且打扰度较低时，虚构主人在回看和继续休息之间有相反偏好。动作由当时的组合策略采样。只有落在这两个动作内才有一半概率得到显式反馈，对偏好动作的赞同率设为 80%，另一动作设为 20%。没有反馈就跳过。由于这里设定两种反应恰好互补，赞同回看或否定休息都可为偏好回看记一次票。两个计数带相当于各两票的先验，将基础的回看相对休息赔率乘以个人赔率，倍率限制在 0.2–5。此设定便于验证权重隔离，真实主人可能同时喜欢两种反应，届时应按场景和动作分别估计反馈。

同一批 1,500 个场景中，两位虚构主人各给出 127 次反馈，随后冻结档案。下表以留出集中的 728 次温和触摸为样本，列出进入“休息或回看”这一对动作时选择回看的条件概率，按模型概率计算。对每个基础版本，程序也逐项验证理毛、走开的概率及非温和触摸场景的预测不随档案变化。

| 合成数据训练的基础模型 | 空白档案 | 偏爱回看 | 偏爱安静 |
| --- | ---: | ---: | ---: |
| 初版 | 74.0% | 90.4% | 48.1% |
| 用较安静的样本续训后 | 54.4% | 79.1% | 27.6% |

**升级影响**。第二版从初版继续训练，新增 8,192 个场景，只在造数时提高了温和触摸后继续休息的标签概率。对这一新分布的留出样本，两版的负对数似然分别为 0.986 和 0.949。每份档案保留特征与动作协议版本及其学习时的基础权重摘要。程序保存并重读 JSON，验证学习偏好时初版基础权重逐项相同，升级基础时两份档案文件的 SHA-256 相同。两位主人的偏好方向在本次升级后保留，但同一档案的回看率有明显漂移，实际升级前应回放相同的历史场景。

这个实验测量了从预设概率学习和合成偏好对输出的影响。它没有检验真实互动中的反馈含义、长期偏好变化、连续行为是否自然或动画能否执行意图。127 次反馈也不能用来推断主人实际需要互动多少次。

## 指针邀请与熟悉度

停在脸旁、平缓地横向移开、再停在目标处，会形成一次邀请。新的 4→8→2 网络读取脸旁停留时间、引导速度、休息倾向和近期打扰度，决定继续休息或跟几步。[训练脚本](invitation.py) 使用 8,192 个合成桌面场景，4,096 个留出场景上的负对数似然为 0.592，固定频率基线为 0.693。从项目根目录运行 `python3 -B Tools/Research/CatPolicy/invitation.py /tmp/invitation-v1.json` 即可重新生成基础权重。

实际回应还读取达达在这台 Mac 上已经记住的温和互动次数。这个计数来自完成的头背双击，至少相隔半小时才再计一次。桌面版本采用一条经验规则，让 12 次以上的温和互动在完全平静时把接受邀请相对留在原地的赔率乘以 1.5。6 次时倍率约为 1.225。随打扰程度上升，对数赔率的增量线性衰减，打扰度达到 1 时倍率为 1。以空白邀请偏好、脸旁停留 0.75 秒、引导速度 0.85 身长/秒、休息倾向 0.87 为例，完全平静时的接受率从 69.3% 增为约 77.2%。这些幅度是桌面互动的设计参数。

主人明确选择更常跟随或更常留在原地时，只调整邀请档案中的两种反馈计数。达达看了、跟了或留在原地，都不会自动给自己的决定投票。
